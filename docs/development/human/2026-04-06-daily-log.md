### 2026-04-06 (Night Session - 启动同步失败根因修复)

**问题描述**：用户下载 v0.0.7 打包应用后，启动时显示"启动同步失败，请注意核对当前数据状态"。

**根因分析（系统化调试）**：
发现 `src-python/main.py` 存在两个致命 bug，导致 Python 引擎在生产环境中完全无法启动：

1. **Import 错误**（`main.py:7`）：`from engine.data.akshare_source import AkshareDataSource` — 类名不存在，正确类名为 `AkshareSource`。这导致 Python 引擎在模块加载阶段就崩溃。
2. **Database 未初始化**（`main.py:41`）：`db = Database(db_path)` 后未调用 `db.init()`，导致 `self.conn` 为 `None`，任何数据库查询都会抛出 `AttributeError`。注释错误地声称 `__init__` 会自动初始化。

**修复内容**：
- `src-python/main.py:7`：`AkshareDataSource` → `AkshareSource`
- `src-python/main.py:41`：添加 `db.init()` 调用，移除错误注释
- 新增测试 `tests/test_engine_startup.py`（4 个测试用例）：
  - `test_database_without_init_raises_on_query` — 验证未 init 时查询崩溃
  - `test_database_with_init_succeeds_on_query` — 验证 init 后正常
  - `test_main_module_imports_successfully` — 验证 import 无错误
  - `test_main_initializes_db_before_use` — 验证 main() 集成启动正常
