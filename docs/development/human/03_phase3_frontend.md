# 第三阶段开发文档：前端 Vue 页面与可视化 (Human)

## 概述
第三阶段专注于构建用户界面，采用 Vue 3 + TypeScript，通过 Tauri IPC 与 Rust 通信，最终调用 Python 引擎进行数据分析。

## 页面结构与功能
我们设计了五个主要页面，通过左侧导航栏切换：

1. **总览 (Dashboard.vue)**
   - 全局状态概览：基金总量、今日信号、待分析数量、引擎运行状态
   - 快速操作按钮：启动/停止引擎、同步数据
   - 今日信号列表，展示代码、名称、现价、评分、形态、信号和详情入口

2. **形态筛选 (Screening.vue)**
   - 筛选条件选择（V型反转、放量突破等）
   - 今日筛选结果卡片展示，包含形态强度与现价

3. **技术评分 (Scoring.vue)**
   - 基金代码/名称搜索与分析
   - 综合评分圆环图、各维度得分进度条（趋势/动量/波动/量能）
   - 交易建议（建议买入量、预估费用、止损止盈价）
   - K线图表预留位（ECharts）

4. **交易配置 (Config.vue)**
   - 总预算设置
   - 按交易品种（ETF、LOF、股票）分别设置手续费率、最低佣金（免5配置）及印花税
   - 成本测算预览，可以下拉选择任意品种，根据当前配置实时测算所需成本
   - 分析阈值：买入评分、止盈止损

5. **定时任务 (Scheduler.vue)**
   - 已配置任务列表（每日同步、15:30筛选、21:00更新净值）
   - 执行历史日志

## 布局与样式
- 使用 `MainLayout.vue` 作为主布局，左侧固定宽度侧边栏，右侧自适应主内容区
- 配色：深蓝主色调 (#1e3a8a)，绿色代表积极信号，红色代表预警，中性色为信息展示
- 响应式卡片设计，清晰的信息层级
- 所有页面均使用了模拟数据 (mock data)，以便在连接真实后端前预览 UI 效果
