# UI 风格参考与明日调整计划

## 用户指定的风格参考

参考网址：https://a8ab9068-26b0-4577-be71-1a232f036eed.dev.coze.site/

### 关键设计特点

1. **卡片式布局**：
   - 每个基金作为一个独立的卡片
   - 白色背景、圆角、轻微阴影
   - 卡片内部信息分区清晰

2. **视觉层次**：
   - 基金名称和代码：大号字体，突出显示
   - T+0/T+1 标签：用不同颜色的标签区分
   - 价格信息：中等字号
   - **盈亏信息**：用大号字体和颜色高亮（绿色=盈利，红色=亏损，国际标准）

3. **顶部筛选区**：
   - 策略参数：资金规模、目标收益、推荐日期等
   - 标签切换：全部基金、T+0、T+1

4. **色彩方案**：
   - 绿色：正向收益
   - 红色：负向亏损
   - 渐变色和阴影增加层次感

### 重要数据展示方式

- **预期利润**：+¥XX.XX (XX%)，绿色大号字体
- **最大亏损**：-¥XX.XX (-XX%)，红色大号字体
- 其他价格信息：小号字体，灰色
