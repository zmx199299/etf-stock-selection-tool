# 场内基金自动化分析系统 — 设计文档

## 1. 项目概述

**目标**：构建一个跨平台桌面应用，每日收盘后自动采集场内基金数据，执行日内形态筛选和技术指标评分，结合用户实际交易费率输出次日交易建议及盈亏预估。

**核心原则**：

- 最小化实现，无冗余代码
- 本地数据库是唯一数据源，联网仅在数据同步环节发生
- 所有阈值、权重、费率可配置
- 模块化设计，预留扩展接口
- 完善的文档体系
- 每个页面 UI 设计由用户逐一确认后再开发

## 3. 技术架构

```
Tauri 桌面应用
├── Web 前端 (Vue 3 + TypeScript + ECharts + Tailwind CSS)
│   └── 通过 Tauri Command (IPC) 调用后端
├── Rust 中间层
│   ├── Python 子进程生命周期管理 (sidecar)
│   ├── JSON-RPC 消息路由
│   ├── 定时任务调度 (两阶段)
│   └── 系统托盘 / 通知
└── Python 分析引擎 (sidecar 二进制)
    ├── 数据采集模块 (akshare, 可插拔接口)

    ├── 技术评分模块 (pandas + ta-lib)
```

## 4. 数据层设计

### 4.1 设计原则

- 联网仅发生在"数据同步"这一个环节
- 所有分析计算均从本地 SQLite 读取，不再联网查询
- 首次运行爬取上市以来完整历史数据，之后仅增量更新

### 4.2 基金基本信息表 (fund_info)

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| code | TEXT PK | 基金代码 | 510300 |
| name | TEXT | 基金名称 | 沪深300ETF |
| fund_type | TEXT | 产品形式 | ETF / LOF / 封闭式 / REITs |
| invest_type | TEXT | 投资类别 | 股票型 / 指数型 / 商品型 / 跨境型(QDII) / 行业主题型 / REITs / 其他 |
| t_plus | TEXT | 交易属性 | T+0 / T+1 |
| list_date | TEXT | 上市日期 | 2012-05-28 |
| is_excluded | INTEGER | 是否排除 | 0=否, 1=是(货币/债券) |

基金列表每日更新：新上市基金自动纳入，退市基金自动标记。

### 4.3 日线行情数据表 (daily_quote)

| 字段 | 类型 | 说明 |
|------|------|------|
| code | TEXT FK | 基金代码，关联 fund_info |
| date | TEXT | 交易日 |
| open | REAL | 开盘价 |
| close | REAL | 收盘价 |
| high | REAL | 最高价 |
| low | REAL | 最低价 |
| volume | REAL | 成交量（手） |
| amount | REAL | 成交额（元） |
| nav | REAL | 基金净值（单位净值） |
| premium_rate | REAL | 折溢价率 = (close - nav) / nav |
| prev_close | REAL | 昨收价 |
| is_suspended | INTEGER | 是否停牌 0/1 |
| suspended_days | INTEGER | 累计连续停牌天数 |
| 主键 | | (code, date) 联合主键 |

### 4.4 停牌判定规则

- 当日成交量 = 0 → 停牌
- 开盘 = 收盘 = 最高 = 最低 且 成交量极低 → 停牌
- 连续停牌天数自动累计，恢复交易后归零

### 4.5 数据源扩展接口

数据采集模块设计为可插拔接口。当前实现 akshare，未来可扩展 tushare、Wind 等，只需实现统一接口即可接入。

## 5. 功能一：日内形态筛选

### 5.1 筛选条件

全部从本地数据库计算：

| 序号 | 条件 | 公式 |
|------|------|------|
| ① | 振幅 3.5% ~ 4.5% | (high - low) / prev_close |
| ② | 先跌 ≥ 1% | (low - prev_close) / prev_close ≤ -1% |
| ③ | V型反转 | high > low |
| ④ | 连续 N 天满足①②③ | 默认 N=3 |
| ⑤ | 次日买入评分 ≥ 阈值 | 默认 60 分 |
| ⑥ | 下一交易日未停牌 | — |
| ⑦ | 折溢价率在合理区间 | 默认 -5% ~ 3% |
| ⑧ | 非货币/债券基金 | is_excluded = 0 |

### 5.2 可配置参数

| 参数 | 默认值 |
|------|--------|
| amplitude_min | 3.5% |
| amplitude_max | 4.5% |
| min_drop | -1% |
| consecutive_days | 3 |
| score_threshold | 60 |
| premium_rate_min | -5% |
| premium_rate_max | 3% |

| 投资类别 | 股票型 / 指数型 / 商品型 等 |
| T+0 / T+1 | — |
| 是否停牌 | — |
| 折溢价率 | — |
| 次日买入评分 | 0~100 |

## 6. 功能二：技术指标评分与次日预测

### 6.1 技术指标体系

| 类别 | 指标 |
|------|------|
| 趋势类 | MA5/10/20/60, EMA12/26, MACD(DIF/DEA/柱) |
| 动量类 | RSI(6/12/24), KDJ(K/D/J), WR |
| 波动类 | BOLL(布林带), ATR(14) |
| 量价类 | OBV, 量比, 换手率 |

### 6.2 综合评分模型

满分 100，四大类加权：

| 类别 | 默认权重 |
|------|----------|
| 趋势类 | 30% |
| 动量类 | 25% |
| 波动类 | 20% |
| 量价类 | 25% |

各类别内部单项指标也有可配置权重。

### 6.3 次日预测信号

| 评分区间 | 信号 |
|----------|------|
| 80 ~ 100 | 强烈看多 |
| 60 ~ 79 | 看多 |
| 40 ~ 59 | 中性 |
| 20 ~ 39 | 看空 |
| 0 ~ 19 | 强烈看空 |

### 6.4 次日买入价值评分

| 维度 | 默认权重 |
|------|----------|
| 技术指标综合评分 | 40% |
| 折溢价率得分 | 20% |
| V型反转强度 (收盘-最低)/(最高-最低) | 15% |
| 连续天数加成 | 10% |
| 成交量变化（量比） | 15% |

### 6.5 止盈止损计算

| 价格 | 公式 |
|------|------|
| 建议买入价 | 当日收盘价 |
| 建议止盈价 | 买入价 × (1 + ATR(14)/收盘价 × 止盈系数)，默认系数 1.5，可配置 |
| 建议止损价 | 买入价 × (1 - ATR(14)/收盘价 × 止损系数)，默认系数 1.0，可配置 |

### 6.6 扩展接口

- 新增指标：实现统一接口，注册到对应类别
- 新增评分维度：实现接口并配置权重
- 未来可接入机器学习模型替换规则评分

## 7. 交易成本与资金分配

### 7.1 用户费率配置

| 配置项 | 默认值 |
|--------|--------|
| 佣金费率 | 0.025% |
| 是否免5 | 否 |
| 最低佣金 | 5 元 |
| 过户费 | 0.001% |

### 7.2 资金分配流程

```
第一步：用户填写总本金（如 50,000 元）
         │
         ▼
第二步：系统展示命中基金列表，默认均分
        页面顶部实时显示：
        · 总本金
        · 已分配金额
        · 剩余可分配金额
         │
         ▼
第三步：用户可手动修改每只基金的分配金额
        每次修改实时更新：
        · 剩余可分配金额
        · 可买份数、盈亏预估、预警级别
         │
        若已分配 > 总本金：
        · 红色提示"已超出预算 X 元，请调整"
        · 禁止确认
```

**三种分配模式**：

- **均分**：一键将总本金平均分配给所有命中基金
- **智能分配**：根据评分高低加权分配，同时规避手续费预警
- **手动分配**：逐只填写金额，系统实时校验不超预算

### 7.3 可买份数计算

```
买入佣金预估 = max(分配金额 × 佣金费率, 最低佣金)
  若免5: 买入佣金预估 = 分配金额 × 佣金费率
实际可买金额 = 分配金额 - 买入佣金预估
可买份数 = floor(实际可买金额 / 买入价 / 100) × 100
实际买入成本 = 可买份数 × 买入价 + 实际佣金
```

### 7.4 盈亏预估计算

```
卖出佣金 = max(卖出价 × 可买份数 × 佣金费率, 最低佣金)
  若免5: 卖出佣金 = 卖出价 × 可买份数 × 佣金费率
卖出过户费 = 卖出价 × 可买份数 × 过户费率
卖出净收入 = 卖出价 × 可买份数 - 卖出佣金 - 卖出过户费

盈亏 = 卖出净收入 - 实际买入成本
盈亏比例 = 盈亏 / 实际买入成本
手续费合计 = 买入佣金 + 卖出佣金 + 卖出过户费
手续费占利润比 = 手续费合计 / 盈亏（仅盈利时计算）
```

### 7.5 手续费预警

| 级别 | 条件 | 提示 |
|------|------|------|
| 红色警告 | 手续费占止盈利润 > 50% | "手续费将吞噬超过一半利润，强烈建议增加投入或放弃" |
| 橙色警告 | 手续费占止盈利润 > 30% | "手续费占比较高，建议增加投入摊薄成本" |
| 黄色提示 | 触发最低佣金（不免5） | "买卖各收取最低佣金，合计固定成本 X 元" |
| 绿色 | 手续费占比 ≤ 30% | 正常 |

分配金额不足买入 100 份时，提示"资金不足，无法买入该基金"。

## 8. 系统配置

所有可配置参数统一存储在 SQLite 配置表中，前端"系统配置"页面集中管理：

- 筛选参数（振幅、跌幅、连续天数、评分阈值、折溢价区间）
- 评分权重（四大类权重、次日买入评分各维度权重）
- 止盈止损参数（止盈系数、止损系数）
- 交易费率（佣金、免5、最低佣金、过户费）
- 调度时间（阶段一、阶段二时间）

修改后立即生效，下次运行分析时使用新值。

## 9. 任务调度

### 9.1 两阶段运行

| 阶段 | 默认时间 | 执行内容 |
|------|----------|----------|
| 阶段一 | 15:30 | 同步行情数据 → 技术指标计算 → 评分 → 筛选（净值标记待更新） |
| 阶段二 | 21:00 | 同步净值数据 → 计算折溢价率 → 更新评分和筛选结果 → 通知用户 |

阶段二净值未更新时每 30 分钟重试，最晚 23:00 放弃。

### 9.2 运行流程

```
触发（定时/手动）
  → 判断交易日（周末/节假日跳过）
  → 数据同步（唯一联网环节）
  → 数据预处理（折溢价率、停牌判定）
  → 技术指标计算
  → 综合评分
  → 日内形态筛选
  → 止盈止损计算
  → 结果写入数据库
  → 通知用户"分析完成"
```

非交易日（周末、法定节假日）自动跳过。

### 9.3 运行日志

记录每次运行的开始时间、结束时间、处理基金数、筛选命中数、错误信息。
